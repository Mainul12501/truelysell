<h1>Install the Project</h1>
<p>Clone the project from Github.</p>
<code>
git clone https://github.com/Mainul12501/truelysell.git
</code>
<h3>If vendor folder doesn't contain in the project then kindly follow these steps.</h3>
<p>Go to project root directory.</p>
<code>cd (project Name) </code>
<p>Download necessary dependency by running this command.</p>
<code>composer update </code>
<p>Then change database informations at <code>applications > config> database.php</code></p>
